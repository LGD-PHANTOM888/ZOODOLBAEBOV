# XXXLGDXXX // Cyber Archive

Тёмный Astro-сайт вместо Quartz: Explorer, заметки, теги, глобальный граф, **графы по папкам** и полноценный просмотр Obsidian `.canvas` (картинки, видео, заметки, связи, панорама и масштаб).

## Как это работает

1. `update-site.bat` запускается на вашем компьютере.
2. `scripts/sync-vault.mjs` читает папку `Public` из Obsidian (путь в `sync.config.json`).
3. Заметки и медиа копируются в `src/content/notes`, `public/media`, `src/data/manifest.json`.
4. `npm run build` собирает статический сайт в `dist/`.
5. Если настроен GitLab remote — изменения коммитятся и пушатся.
6. GitLab CI/CD после пуша в `main` публикует `dist/` через GitLab Pages.

> GitLab **не имеет доступа к вашему Obsidian-хранилищу**. В CI собирается то, что уже закоммитил `.bat`. ПоэтомуGenerated-файлы (`src/content`, `src/data`, `public/media`) должны лежать в репозитории — `.bat` делает это автоматически.

## Первый запуск

### 1. Node.js

Установите Node.js 20 LTS: https://nodejs.org

### 2. GitLab

- Зайдите на https://gitlab.com и создайте **новый проект**.
- Бесплатный план: без банковской карты, 10 ГБ репозиторий + LFS, GitLab Pages до 1 ГБ.
- Рекомендуется **Private**, если в заметках есть личные данные.

В папке проекта:

```bat
git init
git remote add origin https://gitlab.com/ВАС_ИМЯ/ВАС_ПРОЕКТ.git
git add -A
git commit -m "initial cyber archive"
git pull --rebase origin main
git push -u origin main
```

Дальше достаточно запускать `update-site.bat`.

### 3. Проверка локально

```bat
npm ci
npm run dev
```

`npm run dev` тоже делает синхронизацию перед запуском dev-сервера.

## Ежедневное обновление

**Двойной клик по `update-site.bat`.**

Он сам:

- перечитает `Public`;
- скопирует новые/изменённые файлы;
- пересоберёт графы и холсты;
- сделает `npm run build`;
- закоммитит и запушит в GitLab (если remote настроен).

Если GitLab remote не настроен — просто соберёт сайт в `dist\`.

## Что где находится

| Путь | Что это |
| --- | --- |
| `/` | главная: статистика, свежее, папки, холсты, теги |
| `/notes/` | все заметки по разделам |
| `/notes/<slug>/` | заметка или интерактивный холст |
| `/tags/` | теги |
| `/graph/` | глобальный граф связей |
| `/graph/folder/.../` | автоматический граф каждой папки и подпапки |
| `/search-index.json` | индекс для поиска |

Пconductник открывается кнопкой в шапке или клавишей **E**. Поиск — **Ctrl+K**.

## Холсты

`.canvas` больше не являются ссылкой на скачивание. Для каждого холста:

- сохраняются координаты, размеры и связи;
- файлы-картинки и видео показываются прямо на холсте;
- ссылки на заметки открывают эти заметки;
- скрытые/исключённые файлы отображаются как `СКРЫТО`;
- есть панорама, колесо масштаба и кнопка «ВМЕСТИТЬ».

Очень большие холсты (например, 144 узла) по умолчанию вписываются целиком — это нормально, что масштаб маленький. Приближайте колесом или кнопкой `+`.

## Настройки

`sync.config.json`:

```json
{
  "vault": "D:\\...\\Public",
  "siteTitle": "Зоопарк Долбоебов",
  "siteDescription": "Заметки, архив и всё остальное",
  "exclude": [".obsidian", ".trash", ".git", "private/", "Личные данные", "Аккаунты"],
  "includeSensitive": false
}
```

### Важно про приватность

По умолчанию исключаются служебные папки и файлы с личными данными (сейчас 33 файла). Если вы **действительно** хотите публиковать абсолютно всё:

- поставьте `"includeSensitive": true`;
- сделайте GitLab-проект **Private**;
- убедитесь, что у людей есть согласие на публикацию их данных.

Без этого `.bat` всё равно копирует «обычные» файлы, а конфиденциальные пропускает.

## GitLab Pages и лимиты

- Репозиторий GitLab Free: 10 ГБ, файл до 100 МБ на бесплатном плане.
- GitLab Pages: **1 ГБ** на сайт.
- Сейчас медиа ~155 файлов; если сайт вырастет больше 1 ГБ — используйте внешнее хранилище или уменьшайте видео.

`.gitlab-ci.yml` уже настроен: `npm ci` → `npm run build` → `public/` → Pages. Переменные `SITE_URL` и `SITE_BASE` вычисляются автоматически из `CI_PAGES_URL`, вручную их задавать не нужно.
